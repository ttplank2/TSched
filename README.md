# TSched

A weekly schedule app. Your week repeats, so you add each event once. TSched is a student project, made with Claude Code for a University of Illinois course.

There are two versions:

- **[Android Version](Android%20Version)**: the full app for Android phones. Download the APK and install it.
- **[Browser/Apple Version](Browser/Apple%20Version)**: a browser version that works on an iPhone (add it to your Home Screen), a computer, or any phone. It is not fully tested and is lacking a few features.

Everything is saved on your own device only. There is no account, and nothing is sent anywhere.
